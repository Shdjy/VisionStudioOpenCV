## 1. 界面布局与工作区介绍

## 2. 核心操作流程：5 分钟快速上手

### 步骤 1：加载输入图像
- 点击工具栏的 **「打开图像」** 图标（或使用快捷键 `Ctrl+O`），选择本地任意格式图像（支持 `.png`, `.jpg`, `.bmp`, `.tiff` 等，含完整 UTF-8 中文路径支持）。
- 软件启动时会自动载入内置的测试标准图，您也可以直接在测试图上开展实验。

### 步骤 2：浏览并添加算子
- 在左侧 **「算子库」** 面板中，可以通过顶部的 **搜索框** 快速输入关键字（如 `canny`、`高斯`、`阈值`、`模板` 等）。
- **双击** 算子名称，或者将其 **拖拽** 至下方的 **「流水线序列」** 面板中，该算子将立即被追加至流水线末端并自动执行。

### 步骤 3：交互式调节参数
- 在 **「流水线序列」** 中点击选中某一算子节点。
- 右侧的 **「参数调节与原理」** 面板会动态生成对应的控件（滑块 Slider、微调框 SpinBox、下拉框 ComboBox、文件路径选择器等）。
- 拖动滑块时，中央视口将实时更新处理结果，无需手动点击“运行”。

### 步骤 4：对比前后处理效果
- 开启中央视口顶部的 **「帘幕对比」** 开关。
- 拖动视口中央的垂直分屏线，即可直观对比“处理前”与“处理后”的细微边缘、噪点去除或特征提取差异。

### 步骤 5：复制或导出工业级代码
- 按快捷键 `Alt+C` 或点击工具栏的 **「代码生成面板」** 图标，唤出底部代码生成视口。
- 在顶部切换语言（**C++ (OpenCV)** 或 **Python (cv2)**）。
- 点击 **「复制全部代码」** 或 **「导出为文件」**，直接将算法逻辑复制到实际工程中运行。

## 3. 图像视口深度交互操作

### 3.1 平移、缩放与自适应显示
- **滚轮缩放**：向前滚动鼠标滚轮放大图像，向后滚动缩小图像。缩放始终以当前鼠标光标所在像素点为中心。
- **平移拖拽**：按住 **鼠标右键** 或 **鼠标中键** 拖动画布，可在任意放大倍数下自由平移视口。
- **适应窗口 (Fit Window)**：双击鼠标左键，或点击视口工具栏的 **「适应窗口」** 按钮，图像将自动缩放至当前视口最佳尺寸。
- **1:1 原始像素 (100%)**：点击视口工具栏 **「1:1」** 按钮，按真实物理像素无损展示。

### 3.2 前后效果帘幕分屏对比 (Split View)
在调试边缘检测、滤波平滑、对比度增强或形态学运算时，肉眼难以精确捕捉细微像素变化：
1. 点击视口工具栏的 **「帘幕对比 (Split View)」** 按钮开启分屏模式。
2. 图像视口中央会出现一条交互式垂直分割线。
3. **左侧** 显示流水线上一步（或原始图）的输入图像，**右侧** 显示当前算子处理后的输出图像。
4. 按住鼠标拖动分割线左右滑动，实时观察局部细节的明暗、边缘锐度与结构变化。

### 3.3 实时像素探针 (Pixel Inspector)
- 鼠标在图像视口中移动时，视口底部状态栏会毫秒级显示当前鼠标所在的：
  - **物理坐标**：`(X, Y)`
  - **颜色分量**：RGB 像素值 `(R: 215, G: 80, B: 45)`
  - **色彩空间**：HSV 分量 `(H: 12, S: 79%, V: 84%)` 或灰度值 `(Gray: 114)`
- 极大地方便了阈值分割（Threshold）、颜色范围过滤（inRange）等算子的阈值初值选取。

## 4. 流水线管理与增量调试

### 4.1 算子添加与搜索
- 算子库按 OpenCV 知识体系划分为 **11 大业务分类**，支持中英文模糊双向检索。
- 支持直接拖拽算子插入到流水线的指定位置（例如插入到第 2 步与第 3 步之间）。

### 4.2 流水线节点顺序调整与启禁用
- **复选框启禁用**：每个流水线步骤左侧均有 CheckBox 复选框。取消勾选即可跳过该算子的处理（下游算子将自动接收上一个有效算子的输出），无需删除算子即可验证其必要性。
- **上移 / 下移**：选中算子后，通过右键菜单或按钮可调整执行先后次序。
- **删除步骤**：按 `Delete` 键或右键选择 **「删除步骤」**。

### 4.3 单步断点调试与全流程执行
- **单步断点查看**：在流水线列表中单选任意步骤，中央视口将立即切换显示 **该步骤执行完毕后的图像状态**，而非只能看最后一步，实现类似于 IDE 代码调试的“逐步单步检查”。
- **单步执行耗时**：流水线列表每一行右侧实时显示该算子的执行耗时（如 `0.85 ms`），帮助快速定位性能瓶颈算子。
- **增量计算引擎**：当修改第 $k$ 步算子的参数时，VisionStudio 仅从第 $k$ 步开始向下重算，第 $1 \sim k-1$ 步直接复用内存缓存，保证百兆像素图依然流畅。

## 5. 参数调节与算法原理教学

### 5.1 动态参数面板
每个算子根据其元数据动态呈现输入控件：
- **整型 / 浮点型滑块**：支持步长联动微调，拖动滑块与键盘方向键均可操作。
- **奇数核大小约束**：如高斯滤波、中值滤波的核大小（`ksize`）会自动约束为只能选择正奇数（3, 5, 7, 9...），避免 OpenCV 底层报错。
- **枚举下拉框**：如颜色转换（`BGR2GRAY`, `BGR2HSV`, `BGR2Lab`）、插值方式（`Nearest`, `Linear`, `Cubic`, `Lanczos4`）均提供中文友好选项。
- **外部模板/文件路径选择**：如模板匹配算子（`MatchTemplate`）支持直接浏览本地磁盘图像作为模板。

### 5.2 算法原理与教学提示
每个算子面板下方均集成了 **「算法原理与数学公式」**：
- 详细介绍该算子的数学公式（如高斯核公式、CLAHE 裁剪限制原理、Canny 双阈值滞后跟踪机制）。
- 提供工业现场调参经验建议与常见坑点规避技巧。

## 6. 交互式掩码编辑器 (Mask Editor)

VisionStudio OpenCV 提供了强大的交互式局部选区工具，用于实现 ROI 局部滤波、缺陷修补（Inpaint）、局部打码或区域提取。

```
+-------------------------------------------------------------+
|               🎭 交互式掩码与选区编辑器 (Alt+M)              |
+-------------------------------------------------------------+
|  工具箱: [ 🖌️ 画笔 ] [ 🧼 橡皮擦 ] [ ⬛ 矩形 ] [ ⭕ 椭圆 ]    |
|  辅助:   [ 🌓 亮度阈值自动提取 ] [ 🔄 选区反相 ] [ 🧹 清空 ]   |
+-------------------------------------------------------------+
|                                                             |
|                   主交互涂抹画布                            |
|       (支持在当前图像上半透明高亮绘制目标 ROI 掩码)          |
|                                                             |
+-------------------------------------------------------------+
|  笔刷大小: [======|====] 25 px     羽化/平滑: [===|======] 3 |
|  [ 取消 ]                                    [ 应用至流水线 ]|
+-------------------------------------------------------------+
```

### 6.1 启动掩码编辑器 (Alt+M)
- 点击主工具栏的 **「创建/编辑交互式掩码」** 按钮，或按快捷键 `Alt+M`。

### 6.2 绘制工具与选区生成
1. **画笔工具 (Brush)**：自由手绘任意不规则形状的掩膜区域。
2. **橡皮擦 (Eraser)**：擦除多余绘制的选区。
3. **几何选区 (Rect / Ellipse)**：通过鼠标拉框快速创建规则矩形或圆形 ROI。
4. **阈值自动生成 (Auto Threshold)**：根据当前画笔点击处的像素灰度自动提取连通区域作为掩码。
5. **选区反相 (Invert)**：一键翻转前景与背景。

### 6.3 局部处理与原图混合应用
- 点击 **「应用至流水线」** 后，系统将自动创建一个 `InteractiveMaskOp` 节点，后续的算子即可根据掩码进行局部运算。
- 配合 `BlendWithSourceOp`（与原图混合）算子，可实现诸如“仅在特定工业工件表面进行锐化/去噪，而背景保持不变”的复合效果。

## 7. 多通道直方图与图像统计分析

在主界面右侧 Tab 中切换至 **「直方图与剖面分析」** 面板：
- **多通道分布曲线**：实时绘制 R（红）、G（绿）、B（蓝）三通道曲线以及综合灰度分布柱状图。
- **统计特征值**：
  - **像素总数 (Total Pixels)**
  - **灰度均值 (Mean)**：衡量图像整体明暗。
  - **标准差 (StdDev)**：衡量图像对比度与动态范围。
  - **最大值 / 最小值 (Min / Max)**：定位过曝或欠曝区域。
  - **中位数 (Median)**：抗噪统计特征。
- 直方图随流水线节点的切换而毫秒级刷新，帮助直观评估直方图均衡化（EqualizeHist）、自适应直方图均衡（CLAHE）以及伽马校正（Gamma）的效果。

## 8. 多语言工业级代码生成与导出

VisionStudio OpenCV 核心亮点之一是 **实时无缝生成工业级源码**。生成的代码不仅是简单的 API 调用，还包含了必要的命名空间、类型转换、边界检查与规范的工程结构。

### 8.1 实时 C++ (OpenCV) 代码预览
- 按 `Alt+C` 展开代码生成面板。
- 选定 **C++** 模式，生成的代码可以直接复制并加入工业 C++ 视觉项目中编译。

### 8.2 实时 Python (cv2) 代码预览
- 选定 **Python** 模式，生成的代码可直接使用 Python 解释器执行，极大提高算法原型验证效率。

### 8.3 一键复制代码与导出独立脚本
- 点击 **「一键复制代码」** 将源码放入剪贴板。
- 点击 **「导出为脚本文件」** 可直接保存为 `.cpp` 或 `.py` 脚本文件。

## 9. 工程项目保存与加载 (.json)

VisionStudio OpenCV 拥有完善的工程状态持久化机制：
- **保存工程 (`Ctrl+E` / 导出工程)**：将当前整个流水线的算子类型、参数配置、启禁用状态、ROI 坐标、模板文件路径等完整导出为结构化 `.json` 文件。
- **加载工程 (`Ctrl+I` / 导入工程)**：重新打开历史 `.json` 文件，自动恢复完整的流水线并重新执行。
- **事务级安全性**：加载失败（如 JSON 损坏或算子不匹配）时采用事务回滚机制，不会破坏当前正在调试的工作区。

## 10. 高级算法算子使用实战

### 10.1 模板匹配 (单目标 / 多目标抑制)
- **算子名称**：`MatchTemplate` (位于 **特征提取与模板匹配** 分类)
- **模板来源**：支持 **ROI 区域截取** 或 **外部磁盘图像文件**（支持中文路径）。
- **多目标检测模式**：开启 `multiMatch` 复选框，并调节 `scoreThreshold`（如 0.85）和 `overlapThreshold`，算法将自动基于非极大值抑制（NMS）在全图搜寻所有满足匹配度的目标，并在视口上自动绘制绿色检测矩形框及置信度分数。

### 10.2 RANSAC 鲁棒圆拟合与亚像素测量
- **算子名称**：`RansacFitCircle` (位于 **霍夫特征与几何检测** 分类)
- **应用场景**：工件边缘存在缺口、毛刺、强噪点干扰时的精密圆检测与中心定位。
- **核心参数**：
  - `maxIterations`：最大迭代采样次数（推荐 300~500）。
  - `distanceThreshold`：内点判定距离容差（推荐 2.0 px）。
  - `minRadius / maxRadius`：目标圆半径过滤区间。
- **输出结果**：自动在状态栏与结果面板输出圆心精确坐标 `(Cx, Cy)`、半径 `R` 以及拟合置信度内点占比。

### 10.3 条形码 / QR 码工业级识别
- **算子名称**：`BarcodeQr` (位于 **特征提取与模板匹配** 分类)
- **功能**：自动定位视野内的 QR 二维码或 Code128/EAN13 一维条码，在视口中绘制四边形边界，并在结果面板中输出解码文本。
- *注：真实解码需 OpenCV 构建中包含 `objdetect` 模块支持。*
